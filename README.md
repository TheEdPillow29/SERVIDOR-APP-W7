# WEA-APP-W7
Sistema de seguridad y control de acceso inteligente. Integra la captura y transmisión de video en tiempo real vía protocolo RTSP desde una cámara IP hacia un servidor local. Procesa el flujo con OpenCV para detección/reconocimiento facial de usuarios autorizados y sincroniza los registros en una base de datos en la nube con Supabase
